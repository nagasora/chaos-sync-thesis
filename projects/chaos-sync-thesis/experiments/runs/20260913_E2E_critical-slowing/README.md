## 仮説と事前条件

系は $x'=(1-\kappa)\tan(\beta x)+\kappa\tan(\beta y)$ と交換対称な $y'$ の同時更新。
$\gamma_*=\tanh(\beta\gamma_*)$、$\lambda_0=\log\beta+2\log(1+\gamma_*)$、
$\kappa_c=(1-e^{-\lambda_0})/2$、$\lambda_\perp=\lambda_0+\log|1-2\kappa|$。
これは不変Cauchy測度に関する局所横指数であり、大域同期の保証ではない。

- 主beta=1.2、独立初期値ペア1024組、同じ初期値を全結合に使用。
- delta=kappa-kappa_c: -0.01, 0, 0.001, 0.002, 0.005, 0.01, 0.02, 0.05。
- 観測長: 7500, 15000, 30000。全条件を30000更新し各時点で保存する。結果依存の延長なし。
- 再現性: beta=1.05,1.5、512組、delta=0.002,0.005,0.01,0.02、同じ観測長。
- 初期分布: 独立 $C(0,\gamma_*)$ のx,yからs=(x+y)/2, |d|=|x-y|/2。学習・モデル選択なし。
- 数値感度: beta=1.2、delta=-0.01,0.002,0.01、独立初期値512組、7500更新、線形化許容比eta=1e-4,1e-6,1e-8。
- 線形化は小さい |beta*d| と |beta*d/cos(beta*s)| の両方をeta以下に限定。eta=1e-6が主設定。
- 入口 |d|<1e-8 が10更新連続。出口 |d|>=1e-5。末尾滞在500更新以上を有限窓内の安定滞在とする。
- last_outside は入口前も含めた全時刻で記録する。t=0に外側なら初期値0、内側なら-1。
- 有限窓候補時刻 L_T+1 は最後の外側時刻の翌時刻。ただし末尾500更新未満は未確認とする。永久同期と呼ばない。
- first_entry、再離脱、末尾滞在、未確認率を全初期値について保存。成功例だけの平均からスケーリングを推定しない。

## 検証と反証

H1: 同期多様体上の独立256軌道×32768更新で平均指数を解析式と照合する。誤差0.01以内を数値整合ゲートとし、seed単位の平均・標準誤差を保存する。
H2: 線形化許容比を変えて有限窓末尾滞在率を比較する。差の最大幅0.10を感度ゲートとする。これは厳密な精度収束証明ではない。
H3: 正deltaの末尾確認率95%以上の条件だけを固定した適格条件とし、全初期値の有限窓候補時刻の中央値を比較する。未確認は無限大として中央値の識別可否を判定する。少なくとも4条件で、tau対deltaのlog-log傾きと初期値ペアbootstrap95%区間を記録する。傾き-1は仮説であり、区間に含まれても普遍法則の証明としない。7500と30000で判定が変われば観測長依存を明記する。
H4: 過去積分器の更新回数と極近傍精度を独立高精度一歩計算で監査。旧結果は保存し、修正後の結果と同一視しない。

解析ドリフトによる時間尺度1/|lambda_perp|はdelta^-1だが、揺らぎを含む最終離脱時刻の指数が同じであるとは導けない。有限窓量は停止時刻でないため、そのままKaplan–Meierのイベント時刻として扱わない。
