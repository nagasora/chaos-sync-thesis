# E2F: 同期・条件付きエントロピー・横安定性

2026-09-13。E2Eに続き、出力混合tan二体系について「共通のカオス性を残して、二体系を別々に記述する不確実性が減る」を検証する。結果を見る前の設計をここに記録する。実行数値の正本は config.json、実行後の判定・理論の証明と限界は RESULTS.md とする。

## 対象と再利用

同時更新する $x'=(1-\kappa)\tan(\beta x)+\kappa\tan(\beta y)$、$y'=\kappa\tan(\beta x)+(1-\kappa)\tan(\beta y)$。旧E2の加算結合ではない。E2Eの e2e_dynamics.step を再利用し、元のrunは変更しない。差分は $\log |(x-y)/2|$ で保持し、復元した浮動小数点の x=y を完全同期の判定に使わない。

## 理論と作業仮説

- 厳密な有限アルファベットの連鎖律 $H(X,Y)=H(X)+H(Y|X)$ と相互情報量の恒等式を確認する。
- 同じ量子化で X=Y なら H(Y|X)=0。逆は完全同期の十分条件ではない（反対角の決定的関係も対照に含める）。
- 独立Cauchy初期分布、正の定常尺度、非負の出力混合という条件で周辺閉包を検討する。一般の相関初期分布へ外挿しない。
- 同期面上の横指数 $\lambda_\perp=\lambda_0+\log|1-2\kappa|$ と、実際の非同期アトラクタの全指数を混同しない。
- 負の横指数から、有限時間の条件付きエントロピーの単調減少や大域同期を演繹しない。今回検証するのは有限時間・固定分解能での経験的対応である。

## 数値設計（実行前）

主実験は beta=1.2。結合は0、局所臨界 kc に対して -0.02/-0.01/-0.002/0/+0.002/+0.01/+0.05、および一歩同期対照0.5。独立4バッチ、各4096独立初期値ペアを予定し、同一初期値を結合間で共有する。計算資源により事前に縮小する場合は config.json に最終数を固定してから実行する。

各ペアを0/100/1000/7500/30000更新で観測する。同時刻の独立アンサンブルを使用し、長い一本の軌道を独立標本として数えない。固定座標 $u(x)=1/2+\arctan(x/\gamma_*)/\pi$、等幅8/16/32ビン。結合ごとに分割や尺度を再推定しない。

既存積分器は差の符号を捨てるため、s+|d|、s-|d|を固定ラベルの x,y と誤認しない。交換対称な初期分布・力学を用い、同時度数と転置の平均により交換対称な分布を推定する。標本数は倍増したとは数えない。符号・時間履歴を要する情報量の推定には使わない。

記録するもの：同時度数、周辺/同時/条件付きエントロピー、相互情報量（bit）、量子化不一致率、Fano上界、対数差分と閾値未満率、無効数。シャッフル対照を同一標本数で作り、有限標本による見かけの相互情報量を併記する。プラグイン推定量を真の母エントロピーと断定しない。

別の定常初期アンサンブルで同期面の平均指数と有限時間指数の分布を測定する。単位は自然対数/更新で、エントロピーのbitとは区別する。短い窓と長い窓の横指数の正値率を比較する。追加の線形化切替感度条件は config に記録する。

## 判定条件

1. 実装検証：独立・対角・反対角の既知分布、連鎖律、Fano上界、一歩同期、極小差分保持、保存データの再集計と代表再生を確認する。失敗は科学的反証ではなく実装問題として修正する。
2. 主仮説：T=30000の安定側 kc+0.05 で、各ビン数の H(Y|X) が非結合対照の25%未満、かつ対数差分で小差分率95%以上なら、この有限設定で縮約を支持する。どちらか未達なら強い主仮説は不支持。共通方向の指数は解析値と平均誤差0.02以内か確認する。
3. 臨界：kc±0.002を中心に短窓でも増幅が残るか、T=7500と30000で情報量・小差分率が変わるかを記述する。普遍的臨界指数の新規推定や熱力学的相転移の確定は行わない。
4. 感度：切替閾値を変えた H(Y|X) と小差分率を併記する。差が大きい場合、主計算の数値頑健性は未確立とする。許容誤差を結果後に設定して成功判定しない。

## 再現と成果物

`python entropy_sync.py --preflight`、`--run`、`--validate`。依存するE2E積分器も必要。初期値・snapshot・度数・バッチ別/集計CSV・有限時間指数・図を artifacts に保存し、環境・設定・SHA-256と検証を残す。

この実験で、入力の保持、復号、実符号長、KSエントロピーのPesin公式の適用、全初期値からの同期は確認しない。
