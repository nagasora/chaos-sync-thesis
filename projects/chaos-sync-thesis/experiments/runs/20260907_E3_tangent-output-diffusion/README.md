# E3：タンジェント写像出力の拡散結合

## 事前登録

E2相互加算結合と区別し、F(x)=tan(beta x)に対して
x'=(1-kappa)F(x)+kappa F(y)、y'=kappa F(x)+(1-kappa)F(y)を調べる。
beta>1、0<=kappa<=1。同期上ではs'=F(s)であり、中心Cauchy不変尺度gammaは
gamma=tanh(beta gamma)の正解のまま。一般の非同期二変数分布の閉包は仮定しない。

## 理論と予想（実行前）

同期上のJacobianはF'(s)[[1-kappa,kappa],[kappa,1-kappa]]。
縦倍率はF'(s)、横倍率は(1-2kappa)F'(s)。不変測度上で

    lambda_0=log(beta)+2log(1+gamma),
    lambda_perp=lambda_0+log|1-2kappa|,
    (1-exp(-lambda_0))/2 < kappa < (1+exp(-lambda_0))/2

が局所横安定条件。等号は中立であり収束保証はない。
kappa=1/2では両出力が同じ和となり、有限入力・出力なら厳密実数でも一歩で同期。
この特例の指数は負の無限大であり、有限数値の平均と混ぜずNoneで記録する。
結合行列のモード分解は[master stability functionの原論文](https://journals.aps.org/prl/abstract/10.1103/PhysRevLett.80.2109)
に対応する考え方で、上の離散tan系の式はここでJacobianから導出した。

lambda_0を典型軌道の指数と結びつける際は、E1/E2で整理した尺度適合Cayley像のinner写像・混合性の議論を用いる。
枝内のF'(x)>=betaだけから、極と無限枝を含む大域的ergodicityを結論しない。

負の条件付き指数は、有限距離の初期条件すべての同期を保証しない。
tanの極をまたぐ有限摂動と、有限精度による完全一致・吸収を区別する。
境界近傍では有限時間指数と理論値の符号が異なる可能性がある。

## 固定条件

- beta=1.0001,1.01,1.1,2、32独立seed、各200000step。
- q=-1,-0.25,0,0.25,0.75 とし、kappa=(1-exp((q-1)lambda_0))/2。
  理論横指数がq*lambda_0となる5条件に、kappa=0と1/2を加えた7条件。
  数値走査は下半区間のみ。上半区間との対称性は写像の交換対称性で確認する。
- SeedSequence([20260907,3,beta_index,seed])。各seedで中心s0と独立x0,y0をCauchy生成。
- near初期値: (s0+gamma*1e-8/2,s0-gamma*1e-8/2)。
- independent初期値: 二つの独立C(0,gamma)。同じ初期値を全kappaで使用する。
- 各seedの同期上軌道を一度だけ生成してlambda_0を推定。kappaごとに厳密な対数係数を足し、
  非同期の二軌道統計とは別に保存する。
- 同期判定は最後の20000stepの最大|x-y|/gammaと最大Cayley弦距離がともに1e-6以下。
  初回完全一致時刻(x==y)を別記録。正指数側での完全一致は数値吸収として警告し、
  理論的な安定同期の証拠とはしない。初期時点ですでに同値なら記録し再抽選しない。
- nearの|x-y|/gammaが最初に0.01を超える時刻も記録。収束時間と混同しない。
- 時系列は2の累乗時刻・最終時刻、複素点群は代表seedの等間隔4096点を保存。
  モードz_x conjugate(z_y)の配置も表示し、単に両者が円周にあることと一致を区別する。
- 分率は32seedの記述統計とし、吸引域体積の精密推定や母集団保証とはしない。
- float64、Numba標準tan、fastmathなし。クリップ、ノイズ、再抽選、結果に応じた延長はしない。
- 理論ゲート: 固定尺度、Jacobian、交換対称性、kappa=1/2の一歩同期、
  有限区間の指数恒等式。有限差分基準1e-7、他1e-10。

同じseedの基準系列を共有しているので、結合条件数を独立な確認実験数と数えない。
局所指数の式は数値と整合するが、以下の同期率から同じ境界を確認できたわけではない。

### 有限距離の実験と数値吸収

- 負指数側(q=-1,-0.25): 512/512組で有限時間同期基準を満たし、全例でfloat64完全一致も発生。
- 中立(q=0): 256/256組で完全一致。これを中立点の漸近安定性の証拠にしない。
- 正指数側（非結合対照を含む）: 768組中320組で完全一致。
  非結合256組では0例、正指数の結合512組では320例だった。
- kappa=1/2: 256/256組で一歩目に完全一致。これは実数理論にもある特例と一致する。
- 初期時点の完全一致は0例。すべての反復状態は有限で、サンプル除去は行っていない。

正指数側の完全一致の数（near / independent、各32seed）:

| beta | q=0.25 | q=0.75 |
|---:|---:|---:|
| 1.0001 | 32 / 32 | 32 / 32 |
| 1.01 | 32 / 32 | 31 / 32 |
| 1.1 | 32 / 32 | 0 / 0 |
| 2 | 0 / 1 | 0 / 0 |

**float64の同期率を、そのまま実数系の同期安定境界と解釈してはならない。**
負指数側の観測も有限精度による吸収を含むため、大域的吸引域を証明したとはしない。

### 探索的な80桁診断（主実験後、1例のみ）

CSV順で最初の「正指数かつ完全一致」の例を固定的に選んだ。
これは事前登録の主検定ではなく、数値吸収の原因を調べる追加診断。

beta=1.0001、kappa=0.012750129066687833、near、seed=0で、1696step目に完全一致した。
直前のfloat入力の差は -3.469446951953614e-18。
同じfloat入力とパラメータを正確に80桁へ移して

    (1-2*kappa) * [tan(beta*x_previous)-tan(beta*y_previous)]

を評価すると -3.38290579109571366e-18 であり、ゼロではない。
float64の更新結果では0になった。これにより少なくともこの例では、真の一歩一致でなく
丸めによる同値化が確認された。その後は対角が数値的にも不変なので同値のまま吸収される。
高精度で長時間軌道全体を追跡したわけではない。
入力のhex表現、精度、式、結果はartifacts/roundoff_example.jsonに保存した。
再評価ではfloat.fromhexで復元し、mpmath.mp.dps=80、mpmath.mpf(float値)で正確に移す。

### 解釈と次の行動

Hypothesis: 出力拡散は同期上のtan力学を保ち、横方向の線形安定性を制御できる。
Change: 相互加算から出力混合へ変更し、nearと独立初期化を分離した。
Metric: 同期上指数、実数距離・Cayley弦距離、完全一致時刻、有限時間同期率。
Result: 指数の理論式は整合する一方、正指数側でも多数のfloat64吸収が起きた。
Interpretation: 結合の局所安定性と、有限精度の二軌道が一致する現象は別である。
Next Action: 同期率による境界推定や復号・学習への拡張を行う前に、精度別の吸収時刻と
高精度の局所摂動を、別の固定条件で検証する。ノイズ注入で一致を避けた結果を元の系の結果とはしない。
