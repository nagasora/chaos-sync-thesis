## 研究質問

既知の一般化 Boole 軌道を線形混合した有限時間観測について、TM・時間遅延特徴は、未使用 seed の写像パラメータまたは源信号を基準手法より正確に回収できるか。

## 仮説

周辺分布のロバスト統計だけでは区別できない有限時間の時間構造が TM・時間遅延係数に残り、線形 probe でも回収性能が上がる。改善が生じるなら、TM は「消失情報の復元」ではなく「残存する軌道差の読みやすい座標化」に寄与する。

## 反証条件

- test 軌道で TM 系特徴が raw、自己相関、Fourier、ICA の最良値を上回らない。
- seed ではなく時点をランダム分割した場合にしか改善しない。
- TM 次数またはデコーダ容量を増やした訓練内適合だけで、未使用パラメータへ一般化しない。
- 単一チャネル・同一 Cauchy 分布の識別不能対照まで分離できたように見え、リークまたは評価不備が疑われる。

## データ

- 生成元または取得元: 実数値の一般化 Boole 写像 `F_alpha(x)=alpha(x-1/x)` で人工生成する。
- 入力と目的変数: 観測は `y(t)=A s(t)+eta(t)`。目的は `alpha`、Cauchy 尺度、または源軌道 `s(t)`。
- 条件: 単一源のパラメータ回収、2 源・2 観測の full-rank 混合、2 源・1 観測の識別不能対照。
- 候補パラメータ: `alpha in {0.40, 0.50, 0.60}`。採用前に E0 で対象領域の不変測度と Lyapunov 指数を確認する。
- 軌道数・観測長: pilot は各条件・seed につき burn-in 後 4096 点。
- burn-in: 2048 点。定常初期化対照では理論尺度の Cauchy 分布から開始する。
- train/validation/test の分割単位: 時点ではなく軌道 seed。test の seed とパラメータ組は学習に使わない。
- Cauchy サンプリングを使う箇所と理由: 定常初期化の対照だけに使い、各時刻の外部入力には使わない。

## 方法

- 前処理: train から求めた中央値・IQR によるロバスト尺度化。test へ再適合しない。
- モデルまたは写像: まず同期結合を入れず、線形混合だけを観測写像とする。
- TM 基底の定義と尺度: Cayley 変換に基づく有限次数 `|k|<=8` を候補とし、尺度は train のみで選ぶ。
- 時間遅延: `tau in {0, 1, 2, 4, 8}` の窓付き係数を比較する。
- 学習方法: 同一の ridge 線形 probe を全特徴へ用いる。源分離では ICA と、既知混合行列を用いる oracle を比較する。

## 比較対象とアブレーション

- ベースライン: median/IQR/quantile、raw 窓、Fourier、自己相関、PCA、ICA、oracle。
- 除去する構成要素: TM なし、遅延なし、カオスなし、混合なし、位相ランダム化。

## 学習設計

- 学習するパラメータ: ridge 線形 probe の読み出し重みと切片。
- 固定するパラメータ: 一般化 Boole 写像、人工源、線形混合行列、TM 特徴の候補集合。
- 状態時間 `t` と学習ステップ `n` の更新順: 軌道を固定パラメータで生成した後、train 軌道から読み出しを学習する。
- 損失項と各重み: パラメータ回収はロバスト回帰損失、源回収は整合後の回収誤差。エントロピー最小化はまだ導入しない。
- 結合行列の制約: E1A では同期結合を導入しない。
- optimizer、勾配 clipping、停止条件: ridge は閉形式または安定な線形 solver を用い、正則化係数は validation で選ぶ。
- test 時に凍結する対象: 読み出し、前処理、TM 尺度、基底次数をすべて凍結する。

## 評価

- 主指標: パラメータ回収 RMSE、permutation・符号・尺度を整合した源回収相関。
- 副指標: Cauchy 尺度誤差、KS 距離、bounded-kernel MMD、Amari 型誤差、計算時間、特徴次元。
- seed 間の集約方法: seed 別値、中央値、四分位範囲、paired bootstrap 信頼区間を保存する。
- 成功条件: 未使用 seed で TM 系と最良ベースラインの差の信頼区間が改善側にあり、識別不能対照では過大な分離性能を示さない。
