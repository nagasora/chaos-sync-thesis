# E3D: 状態同期と Cauchy 周辺分布の一致を分離する

Status: completed。以下の事前条件は本計算前に固定し、結果を末尾へ追記した。調整・実装: root、理論構築: theory_builder、独立監査: theory_auditor。

## 仮説・事前条件

写像は F(x)=tan(βx)、出力拡散は X'=(1−κ)F(X)+κF(Y), Y'=κF(X)+(1−κ)F(Y)。β=1.01,1.1,1.5,2、κ=0,.25,.5、seed=810,811,812、各 ensemble N=20000、t=0,...,16、float64。γ*>0 は γ*=tanh(βγ*) の根。main は各pairの両nodeを独立 Cauchy(0,γ*) から初期化する。同一β/seedでκ間は初期値を共有し、pair間は独立とする。訓練・モデル選択・testへの調整は行わない。

- H1: κ=0では全時刻の各周辺は同じ定常Cauchyだが、paired stateは同期しない。bounded Cayley二乗距離 D=N⁻¹Σ|q(X)−q(Y)|² の母期待値は2（qはγ*に整合）。
- H2: κ=.5では t=1 で全pairが代数的に同期するが、定常Cauchy尺度はγ*のままである。独立Cauchyの平均は尺度を半減しない。
- H3: κ=.25ではt=1の各周辺は同じCauchy。t≥2でnode間依存が生じるため、この閉包は未証明。定常CauchyとのKS距離を記述するが定理の合否へ入れない。
- 副対照: κ=0だけで初期 w_A=−.5+.6iγ*, w_B=.5+1.4iγ* を追加。複素位置尺度 w' = tan(βw) と経験分位点/KSを照合する。有限tでの定常分布への接近を記述し、大域収束速度を主張しない。

主指標: node別one-sample KSと理論周辺分布、D、exact float64 equality件数、sample median/半IQR。two-sample KSは記述指標（paired標本に独立2標本検定のp値を使わない）。Cauchyの母平均/分散は使わない。副対照の閉包照合を含む全1272 node/time/seed検査に α=.01 のDKW union bound ε=√[log(2M/α)/(2N)] を使う。各固定時刻でpair indexがiidという数学モデル上の保証であり、float64の分布が厳密に連続Cauchyだとはしない。時間・κ間の独立性はunion boundに不要。seedをpoolしない。

H1のDには [0,4] 有界変数のHoeffding union boundを別α=.01で用いる（204条件）。DKWまたはHoeffding超過は削除せず報告し、実数理論の証明や自動反証とは呼ばない。H2の代数恒等式、float64全件一致、高精度再計算は別に記録する。κ<.5で一致が発生したらその直前値を80桁で再計算し、安定同期の証拠にはしない。非有限値は除外せず停止する。

## 保存・再現・解釈

初期ensemble、全条件の最終状態、各時刻のCSV、config/environment/metrics、図と入力・コード・出力hashを保存する。validatorは保存初期値から再計算し、最終状態・CSV・集計・hashを照合する。既存E3の正横指数下でのfloat64吸収例を踏まえ、本runは16stepの有限精度診断とする。

これは分布と同期の基礎実験であり、入力除去後記憶、雑音除去、入力画像の復元、VAE優位を評価しない。既存E6の負結果はそのまま残す。新しい入力符号化を採用する前に、位置尺度の違いが固定βでどれだけ失われるかを確認する。


## 結果（2026-09-08）

- 48条件、各N=20000、17時刻、node別1632行を保存。解析式との事前1272検査は **1272/1272 がDKW境界内**。最大KS=0.01345870133409377、同時閾値0.01763991433542699。これを理論の証明や一般的な性能合格とは呼ばない。
- κ=0の204距離検査はすべてHoeffding境界内。距離は1.9723250909568517～2.0237667858768877（期待値2、同時半幅0.0651657497782148）。
- κ=.5は全条件・t≥1で全20000pairがfloat64で一致、距離0。各β/seedの一歩目代表pairを80桁で再計算し差0も確認。κ<.5の完全一致は本16stepでは0件。長時間の丸め吸収を否定する結果ではない。
- 解析分布パラメータは80桁で計算して文字列保存。対応するfloat64パラメータ反復との差は最大3.7238012298709097e−16。極接近での実軌道の長時間精度を保証する数値ではない。
- κ=.25の事前探索360 node/time/seed行は最大KS=0.013166667260474663。これは事前DKWの件数へ加えていない。

最終t=16の3seed平均（距離はnode0/1の対、尺度はnode0の標本半IQR）:

同期でpaired距離は変わるが、同じ定常Cauchy尺度を保持する。平均による同期を、そのままCauchy尺度の縮小や雑音除去と呼べない。

heterogeneous副対照では、β=2のt=16で解析位置が絶対値約2.2e−13以下となる一方、β=1.01では位置約−.025/.037・尺度約.382/.351で、定常尺度約.172からなお離れる。位置尺度の入力依存性の残存時間は条件で違う。この実験だけで入力復号や情報量を評価したわけではない。

## 事後の理論拡張・監査記録

κ=.25で周辺が保たれた観測を受け、独立な初期product Cauchyへ積Poisson公式を適用する別証明を構成した。[理論ノート13.6](../../../docs/TANGENT_SYNC_VAE_THEORY.md)に仮定と証明を保存。非負・行和1の標本非依存結合とβ>0のもとでは、各周辺位置尺度は全有限tで複素vector反復に従う。均一定常初期なら全κで定常周辺を保つ。中間状態を独立と仮定した証明ではなく、終端の独立性も保証しない。

事前設計と新定理をtheory_builder/theory_auditorが別々に検討し、条件付き成立を確認した。CSVのclosure_supportedとmetricsのunknownは**事前登録時点の検定集合**を指す。新定理に合わせてフラグや検定数を遡及変更していない。

監査で修正した点: 時変oracleを80桁へ分離、全1272検査を事前固定、未知条件のKSを事前合否から分離、同時分布の積分解を主張しない。
