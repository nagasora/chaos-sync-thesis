# TM型座標のCauchy・タンジェント理論照合
状態: completed（結果はmetrics.jsonを正本とする）

仮説・事前閾値はconfig.jsonに実行前固定した。
既存E0の一般化Boole定式化を再利用し、今回は学習器ではなく理論値の照合を独立に行う。
写像は実数のBoole式およびtan式で評価し、Cayley空間の同一式を両辺に使うだけの確認を避ける。
主対象: 測度適合Gram、遅延相関、有限辞書の射影rank/NMSE、有限軌道での相関。
対照: 参照尺度0.5/2、辞書外へ移るモード、m=3かつ位相ずれ0.17。
学習・モデル選択はなくsplitは不要。求積と有限軌道は別の証拠として保存する。
実行: Python + NumPyで verify_theory.py。
生成物: artifactsの条件別CSV、seed別CSV、SHA-256、metrics.json、environment.json。
限界: oracle尺度、単一写像、float64、有限seed。予測器としての普遍的優位は検証しない。


## 結果
- 主照合80/80通過。Cauchy適合Gram誤差1.60424e-15。
- Boole相関45条件の求積最大誤差1.11023e-16。
- 16 seedの有限軌道相関最大誤差0.00434475。alpha=0.5の虚部に-0.004313の残差がある。
- tan実数写像との共役最大誤差1.86825e-13。
- 射影NMSE最大誤差2.22045e-16、rankは10条件すべて一致。
- 追加の独立確認: 8192点で数値最小二乗射影を適合し、ずらした16384点で検証。10条件すべて理論差1.11023e-16以下。

## 解釈
測度適合、低次相関の識別性、整数タンジェント写像の有限辞書誤差について、理論との数値整合性を支持する。
学習性能の優位、同期、圧縮、未知尺度の頑健性は未検証。
有限軌道は固定長1条件であり、誤差の収束率やCI被覆率は確認していない。
次: 観測長と尺度推定誤差を分けて検証する。
