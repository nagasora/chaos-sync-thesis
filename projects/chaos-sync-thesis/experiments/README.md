## E1: 読み出し単体

- 既知の同期クラスタ、位相差、尺度母数を持つ人工軌道
- TM / GFT / 時間遅延特徴による既知パラメータの回収
- 識別不能になる反例の作成
- E1A では同期系をまだ前段に置かず、既知カオス源の線形混合から開始する
- ICA、Fourier・自己相関、raw 特徴をベースラインにする
- 単一混合・同一分布など、原理的に識別不能な条件を成功例と分ける

2026-08-30進捗: 単一源の周辺尺度を軌道ごとに除き、未使用 `alpha` を読むpilotと48独立seed追試を実行した。TM時間遅延はtest RMSE `0.002096`、Fourier帯域は `0.002356` だったが、差の95%区間 `[-0.000023, 0.000561]` は0を含み、TM優位の事前ゲートは未達だった。一方、遅延なしTM `0.090291`、時刻順破壊TM `0.099228` まで悪化し、時間構造が必要という観察は再現した。詳細は [pilot](runs/20260830_E1A_temporal-alpha-readout/README.md) と [独立seed追試](runs/20260830_E1A_temporal-alpha-replication/README.md) を参照する。

2026-09-01進捗: [16次元容量一致追試](runs/20260901_E1A_matched-capacity-readout/README.md) を新規48 test seedで実行した。grouped CVで選んだTM短遅延16次元はtest RMSE `0.001342`、Fourier 16次元は `0.002614` で、差の95%区間 `[0.000985, 0.001560]` は0より大きかった。全TM80次元は `0.001318`、遅延なしTM16次元は `0.094659` だった。容量差だけでは前回のTM改善を説明できないが、TM側の候補選択自由度、単一源・補間alphaという限定は残る。特徴NPZ、全CSV、PNG、コード・artifact SHA-256、独立検証19項目をrun内に保存した。

2026-09-01進捗: [2源識別可能性対照](runs/20260901_E1B_two-source-identifiability/README.md) を実行した。既知full-rank 2観測を逆変換したoracle TMの順序付きtest RMSEは `0.002083`、direct TMは `0.007740` だった。対称1観測では全352衝突対の特徴差が `0.0`、順序付きRMSEの理論下限は `0.073030` で、TM `0.073710`、Fourier `0.073891` は下限を下回らなかった。したがって、可逆観測では2源alphaを読める正対照と、源入替えで情報を失う厳密な失敗対照を同時に確認した。使用源軌道NPZ、特徴NPZ、全CSV、PNG、SHA-256を保存し、独立validator 20/20項目を通過した。

2026-08-31進捗: [E3A有限サイズ同期転移pilot](runs/20260830_E3A_finite-size-sync-transition/README.md) を792条件で完走した。一様正結合の持続同期K50は `0.4875`（95% bootstrap区間 `[0.475, 0.525]`）で、理論値 `0.5` と整合した。同一 `E|eps|=1` の分布普遍性は、最大Nで全分布が持続同期へ達しなかったため判定不能。符号付き平均に沿う秩序差とTM秩序の`N^-1/2` floorはpilot支持となった。

続く [一様正結合10-seed確認](runs/20260831_E3A_uniform-positive-confirmation/README.md) は `N=64,128,256,512`、burn-in/評価各1000、臨界近傍細密格子の800条件を完走した。最大N・localの持続同期K50は `0.465625`（95%区間 `[0.4625, 0.475]`）で、事前基準 `K_c=0.5±0.05` を満たした。これによりP1/H1は確認実験として支持する。H2/H3は10-seed確認をまだ行っていないためpilot結論のまま保持する。

## 各実験の必須保存物

- 事前仮説、反証条件、分割、指標、成功条件を固定した `config.json` または同等の設定
- 実際に使用した入力データ。容量上複製しない場合は、決定論的生成に必要な由来、seed、識別子、ハッシュ、生成コード
- モデルへ入力した前処理後データまたは特徴の機械可読ストア
- 実行コード、再利用コマンド、実行環境、依存版、seed、split
- 集約値だけでなくtest予測、seed別・条件別結果を含むCSV/JSON
- 図の元データと、再生成可能なPNG等のプロット結果
- コードと保存artifactのSHA-256、および独立validatorの結果
- 成功・失敗の両方を含む結果、限定的解釈、次の実験への判断
