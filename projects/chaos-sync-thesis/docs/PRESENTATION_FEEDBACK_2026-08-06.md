# 発表フィードバック整理（2026-08-06）

## 結論

次の最小実験では、結合系や画像入力へ進む前に、人工的なカオス軌道の線形混合から既知の情報を TM 基底で読み出せるかを検証する。

ただし、検証する主張は「TM 基底が、すでに失われた情報を復元する」ではない。正確には、有限時間軌道・不変測度・時間相関に残っている入力依存差を TM 特徴が分離しやすい座標へ写せるか、である。全入力が同一のアトラクタと同一の不変測度へ収束し、観測可能な差が消えた後では、TM 基底を含む後段処理だけで元情報を取り戻すことはできない。

## フィードバックごとの整理

### 1. データをどのように入力するか

「入力」を次の三つに分ける。

1. 復元・識別したい情報 `u`
2. `u` を力学系へ埋め込む写像 `Phi(u)`
3. 数値実験上の初期値、外乱、観測ノイズ

最初の E1A では、複数の既知カオス源 `s_j(t)` を生成し、

\[
y_i(t)=\sum_j A_{ij}s_j(t)+\eta_i(t)
\]

という線形混合を観測データにする。既知情報は、源の個数、写像パラメータ、Cauchy 尺度、混合行列、初期値、乱数 seed である。

Cauchy サンプリングは用途を限定する。

- 定常 Cauchy 測度から開始する対照では、初期値を該当する Cauchy 分布から標本化する。
- 非定常初期値から不変測度へ収束する過程を調べる対照では、別分布から開始して burn-in を明示する。
- 各時刻の外部入力を独立 Cauchy 標本に置き換えると、決定論的な時間構造を壊すため、カオス軌道の代用にはしない。

### 2. 評価関数と自由エネルギー

最初から自由エネルギーだけを最適化対象にはしない。まず、情報が読めるかを直接測る。

- パラメータ回収: MAE、RMSE、決定係数
- 源分離: permutation・符号・尺度を合わせた相関、Amari 型誤差
- 再構成: held-out 軌道の MSE またはロバスト誤差
- 分布整合: Cauchy 尺度推定誤差、KS 距離、特性関数距離、bounded-kernel MMD
- 同期を導入した段階: 同期誤差、横断 Lyapunov 指数、復号性能
- 圧縮を主張する段階: 量子化後の符号長と rate-distortion

自由エネルギーは、エネルギーモデルを明示できた段階の候補とする。例えば条件付き分布 `q(z|u)` と目標分布 `p_theta(z|u)` に対して、

\[
\mathcal F(u)
=\mathbb E_{q(z|u)}[E_\theta(z,u)]-T H[q(z|u)]
=T\,D_{\mathrm{KL}}(q(z|u)\|p_\theta(z|u))+C(u)
\]

と置ける。ただし、入力を条件にしない単一の目標分布へ全入力を近づけるだけでは、入力差を消す方向が最適になり得る。そのため、採用する場合も

\[
\mathcal L
=\lambda_{\mathrm{dist}}D(q(z|u),p_\theta(z|u))
+\lambda_{\mathrm{read}}\mathcal L_{\mathrm{read}}
+\lambda_{\mathrm{sync}}\mathcal L_{\mathrm{sync}}
+\lambda_{\mathrm{rate}}R(z)
\]

のように、読み出し・同期・符号長を分離して評価する。自由エネルギーという名称だけで目的関数を決めず、`E_theta`、温度 `T`、比較する二分布、正規化可能性を先に定義する。

### 3. アトラクタと TM 基底

「アトラクタに同期した後、TM 基底でつぶれた情報を解きほぐす」という理解は、そのままでは正しくない。

- TM 基底は、軌道または経験測度に残っている差を係数として表す候補座標系である。
- 全入力が同じ長時間不変測度へ混合した場合、長時間平均 TM 係数も同じになり得る。
- 情報源の候補は、有限時間過渡、Cauchy 尺度、相対位相、時間遅延、クラスタ分割、入力依存アトラクタである。
- したがって、長時間平均だけでなく、窓付き TM 係数と遅延特徴を比較する。

### 4. `x_i` と Boole の意味

原典の `x_i(t)` は実数値の状態変数であり、Boolean 値ではない。`Boole` は一般化 Boole 変換という写像名である。

\[
F(x)=\alpha\left(x-\frac{1}{x}\right),\qquad x\in\mathbb R
\]

この写像を使う重要性は、Boolean 論理を持たせることではなく、条件下で Cauchy 型不変測度、尺度母数の閉じた更新、Lyapunov 指数などを解析的に扱える点にある。

### 5. `tanh` と Cauchy 分布

確認した無限次元ランダム結合系の原典で用いられている局所写像は一般化 Boole 変換であり、`tanh` ではない。さらに `tanh(x)` は `(-1, 1)` に有界なので、その出力自体が実数全体を台とする厳密な Cauchy 分布になることはない。

前活性、結合重み、外場が Cauchy 安定則へ従う別モデルは考えられるが、それは「`tanh` を使うと Cauchy になる」とは別の主張である。採用前に、どの変数の分布を指すかと、その導出または原典を確認する。

### 6. モデルの学習と結合強度

モデルとして利用する段階では、ノード間結合を学習パラメータに含める。ただし、状態時間 `t` と学習ステップ `n` を分け、一つの軌道内では結合を固定し、軌道間で更新する。学習後は結合を凍結して test 軌道を評価する。

エントロピー単独の最小化は、全入力が同じ同期状態へ落ちる表現崩壊を選び得る。量子化後の符号長または離散エントロピーを rate 項とし、復号損失との rate-distortion で評価する。

\[
\mathcal L
=\lambda_{\mathrm{read}}\mathcal L_{\mathrm{read}}
+\lambda_{\mathrm{rate}}R_\Delta(z)
+\lambda_{\mathrm{sync}}\mathcal L_{\mathrm{sync}}
+\lambda_{\mathrm{dyn}}\mathcal P_\lambda
+\lambda_W\Omega(W)
\]

比較は、読み出しだけ学習、スカラー結合 `K` の学習、制約付き結合行列 `W` の学習の順に行う。詳細は [MODEL_TRAINING_DESIGN.md](MODEL_TRAINING_DESIGN.md) に記録する。

## 最初の実験 E1A

### 研究質問

既知の人工カオス源を線形混合した有限時間軌道について、有限個の TM・時間遅延特徴は、既知パラメータまたは源信号を held-out データで回収しやすくするか。

### 段階

1. 単一源: 写像パラメータ、Cauchy 尺度、初期条件の回収可能性を確認する。
2. 多観測線形混合: 源数 `S` 以上の観測チャネルを持つ full-rank な混合行列で源分離を試す。
3. 識別不能対照: 同一の Cauchy 周辺分布を持つ独立源を単一チャネルへ混合し、周辺分布だけでは分離できない条件を示す。
4. 時間特徴: 窓付き TM 係数と遅延特徴が、周辺分布だけでは見えない時間構造を回収できるか調べる。
5. E1A が成立してから、同期系を前段に追加する。

### 比較対象

- 生系列またはロバスト統計量
- Fourier・自己相関特徴
- PCA
- ICA（源分離の標準比較）
- TM のみ
- TM + 時間遅延

### 成功条件と反証条件

- 成功: TM を含む特徴が、未使用 seed・未使用パラメータ領域で、基準手法よりパラメータ回収または源分離を一貫して改善する。
- 部分成功: 回収可能な情報と、長時間平均で消える情報の境界を示せる。
- 反証: TM 特徴が raw・Fourier・ICA を上回らない、または学習系列内でしか成立しない。

## 追加で検討するポイント

### 識別可能性

単一混合、同一分布、同一時間統計の源は原理的に区別できない場合がある。TM 係数の次数を増やすことは、観測に存在しない情報を増やさない。源数、観測チャネル数、混合行列の階数、源ごとの差を先に確認する。

### Cauchy 分布に適した統計

Cauchy 分布では平均と分散が存在しないため、標本平均・分散・通常の二乗誤差だけで分布適合を判断しない。また、有限一次モーメントを要求する Wasserstein-1 距離を無条件に主指標にしない。中央値、四分位範囲、最尤尺度、KS 距離、特性関数距離などを使う。

### データ分割

同じ一本の軌道からランダムに時点を分割すると、自己相関によりリークする。seed または軌道単位で train/validation/test を分け、必要なら Theiler window を置く。TM の尺度母数、基底次数、デコーダも train のみで決める。

### 有限時間と長時間の分離

入力情報が過渡にだけ残る場合と不変測度に残る場合を分ける。観測窓長、burn-in、開始時刻を実験変数にし、性能対観測長の曲線を保存する。

### ベースラインとアブレーション

非カオス系列、位相ランダム化系列、非混合、非同期、TM なし、遅延なしを比較する。カオス、同期、TM のどれが効いたかを個別に判定する。

### 再現性と失敗記録

成功した設定だけでなく、仮説、変更した一要因、失敗条件、未実行項目を残す。各実験は `experiments/runs/<experiment_id>/` に独立保存し、後から同じ ID の結果を上書きしない。

## 現時点の判断

| 論点 | 判断 | 状態 |
|---|---|---|
| `x_i` は Boolean 値か | 実数値。Boole は写像名 | 原典で確認済み |
| TM は失われた情報を復元するか | しない。残存情報の読み出し候補 | 研究上の制約 |
| `tanh` 出力は Cauchy か | 有界出力なので厳密な Cauchy ではない | 数学的制約 |
| Cauchy サンプリングは常に必要か | 定常初期化など目的を限定して使う | 実験設計上の判断 |
| 自由エネルギーを使うか | 条件付き分布と情報保持項を定義後に比較候補とする | 未採用 |
| 最初に同期系を学習するか | まず人工軌道の読み出し単体を検証する | 採用 |
| 結合強度を学習するか | E3で固定結合、学習スカラー、構造化行列を比較する | 採用 |
| エントロピーを単独最小化するか | 表現崩壊を招くため、復号と符号長の複合目的にする | 不採用 |
