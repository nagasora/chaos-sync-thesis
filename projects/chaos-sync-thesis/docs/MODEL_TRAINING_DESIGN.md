# モデル学習と結合強度の設計

更新日: 2026-08-06

## 結論

カオス同期系を「学習するモデル」として扱う段階では、ノード間結合を学習パラメータに含める。ただし、力学系の時刻 `t` と学習更新の時刻 `n` を分ける。

\[
x_i^{(n)}(t+1)
=F_\alpha(x_i^{(n)}(t))
+\sum_j W_{ij}^{(n)}H(x_j^{(n)}(t),x_i^{(n)}(t))
+B_i u(t)
\]

一つの軌道を生成している間は `W^(n)` を固定し、軌道または mini-batch の評価後に

\[
W^{(n+1)}=\mathcal P_{\mathcal C}
\left(W^{(n)}-\eta\nabla_W\mathcal L\right)
\]

と更新する。`P_C` は、対称性、疎性、行和、結合強度範囲などの制約へ戻す写像である。学習終了後は `W` を凍結し、未使用 seed・未使用軌道で評価する。

## 固定結合にも意味がある

すべての力学モデルが内部結合を学習する必要はない。reservoir computing のように内部ダイナミクスを固定し、読み出しだけ学習する構成もモデルとして成立する。本研究では、結合学習の必要性自体を次の比較で検証する。

1. `readout_only`: 力学系と結合を固定し、読み出しだけ学習する。
2. `learned_scalar_coupling`: 結合構造を固定し、全体強度 `K` だけ学習する。
3. `learned_structured_coupling`: 制約付き結合行列 `W` を学習する。
4. `unconstrained_coupling`: 解析条件を外した数値対照。主モデルにはしない。

これにより、性能向上が TM 読み出しによるものか、結合学習によるものかを分離する。

## エントロピー最小化だけでは学習できない

「どのエントロピーを最小化するか」を定義する必要がある。

- ノード状態全体のエントロピー `H(X)` を単独で最小化すると、全ノード・全入力が同じ状態へ落ちる自明解を選び得る。
- 同期誤差やグラフ高周波成分だけを最小化しても、完全同期による情報消失を選び得る。
- 連続変数の微分エントロピーは座標尺度に依存するため、その値だけを圧縮率とみなさない。
- Cauchy 系では平均・分散を使う推定が不安定であり、重い裾によって勾配も外れ値に支配されやすい。

したがって、圧縮目的には量子化した潜在表現 `Q_Delta(z)` の離散エントロピーまたは実符号長を使い、復号損失と組み合わせる。

\[
\mathcal L_{\mathrm{RD}}
=\mathbb E[d(u,\hat u)]
+\beta H(Q_\Delta(z))
\]

第一項が情報保持、第二項が圧縮率を担う。分類の場合は cross-entropy を `H(Y|Z)` の代理にできる。入力分布が固定なら、`H(Y|Z)` の最小化は `I(Y;Z)` の最大化に対応する方向を持つ。

## 推奨する損失関数

最小モデルでは、各項を別々に記録した上で次の複合損失を候補とする。

\[
\mathcal L
=\lambda_{\mathrm{read}}\mathcal L_{\mathrm{read}}
+\lambda_{\mathrm{rate}}R_\Delta(z)
+\lambda_{\mathrm{sync}}\mathcal L_{\mathrm{sync}}
+\lambda_{\mathrm{dyn}}\mathcal P_\lambda
+\lambda_W\Omega(W)
\]

- `L_read`: 入力・既知パラメータ・クラスの復号損失。Cauchy 系では Huber、quantile loss、負の対数尤度も比較する。
- `R_Delta(z)`: 量子化後の推定符号長または離散エントロピー。
- `L_sync`: ノード間同期誤差またはグラフ高周波エネルギー。
- `P_lambda`: 横断方向の収縮と同期多様体内のカオスを守る罰則。
- `Omega(W)`: 疎性、対称性からのずれ、過大な結合、条件数への正則化。

Lyapunov 条件の罰則候補は

\[
\mathcal P_\lambda
=\operatorname{softplus}(\lambda_\perp+m_\perp)
+\operatorname{softplus}(m_\parallel-\lambda_\parallel)
\]

とする。これは `lambda_perp <= -m_perp` と `lambda_parallel >= m_parallel` を促す。ただし、有限時間 Lyapunov 指数の推定誤差を seed 別に記録する。

エントロピー項だけを下げず、必ず `L_read` と各損失項の推移を別々に保存する。合計損失の改善だけで成功と判定しない。

## 結合行列の制約

結合を無制約に学習すると、同期多様体、不変測度、原典の解析条件を壊す可能性がある。

### 理論に近い経路

- ランダム結合 `epsilon_ij` を固定し、スカラー `K` だけ学習する。
- 対称条件を使う場合は `epsilon_ij=epsilon_ji` を保つ。
- 原典の同期領域と Cauchy 尺度が実数になる範囲へ `K` を制限する。
- `K=K_min+(K_max-K_min)sigmoid(kappa)` のように範囲内でパラメータ化する。

この経路は E3A/E3B で用いる。

### モデル指向の経路

差分結合

\[
\sum_j W_{ij}\{h(x_j)-h(x_i)\}
\]

またはグラフ Laplacian を使えば、全ノードが同じ状態の同期多様体を保ちやすい。例えば自由行列 `A` から

\[
S=\frac{A+A^\top}{2},\qquad
W_{ij}=\operatorname{softplus}(S_{ij}),\qquad
L=\operatorname{diag}(W\mathbf 1)-W
\]

と構成できる。

ただし、これは原典の加法的ランダム結合系とは別モデルである。E3C の数値拡張として扱い、原典の Cauchy 閉包や臨界式がそのまま成立するとは主張しない。

## 学習方法の段階

### E1A: 読み出しだけ学習

- カオス軌道と線形混合は固定する。
- ridge 回帰またはロバスト線形 probe を学習する。
- TM 特徴に読み出し可能な情報があるかを先に確認する。

### E3A: 固定結合の走査

- `K` を学習せず、同期臨界を含む範囲を grid で走査する。
- 復号、同期、符号長の Pareto 曲線を作る。
- 学習可能な領域と危険な領域を先に把握する。

### E3B: スカラー結合を学習

- `K` と読み出しパラメータを学習する。
- 次元が小さいため、grid、Bayesian optimization、有限差分、短い rollout の勾配法を比較できる。
- 学習した `K` が固定走査の Pareto 前線と整合するか確認する。

### E3C: 構造化結合を学習

- 対称性、疎性、結合範囲を保つ `W` を学習する。
- truncated BPTT、勾配 clipping、複数 seed mini-batch を使う。
- 固定結合、学習スカラー `K`、同程度パラメータ数の非カオスモデルと比較する。

## カオス系での勾配学習の注意

一般化 Boole 写像では

\[
F'_\alpha(x)=\alpha\left(1+\frac{1}{x^2}\right)
\]

であり、`x` がゼロ近傍を通ると勾配が非常に大きくなる。一方、同期横断方向では勾配が消失し得る。このため、最初から大きな `W` を end-to-end 学習しない。

- まず `K` の走査と低次元最適化を行う。
- rollout 長を段階的に伸ばす。
- 勾配ノルム、状態の最大絶対値、ゼロ近傍通過回数を記録する。
- 数値安定化の clipping や `epsilon` 追加を使う場合、それは写像を変更するため別条件として記録する。
- 重い裾に対して MSE だけに依存せず、ロバスト損失を比較する。

## 学習と評価の分離

- train: 結合、読み出し、TM 尺度など、許可したパラメータを更新する。
- validation: 損失重み、停止時点、結合制約を選ぶ。
- test: 全パラメータを凍結し、未使用 seed・未使用軌道で一回評価する。
- 学習中の時間変化 `W^(n)` と、状態時間内で変化する適応結合 `W(t)` を区別する。

`W(t)` を軌道内でも更新する可塑性モデルは将来候補だが、非自律系になり、固定結合を仮定する不変測度と同期臨界の理論から外れる。卒論最小スコープでは、まず `W^(n)` を軌道間で更新し、軌道内では固定する。

## 判定したい研究質問

1. 固定結合に対して読み出しだけ学習すれば十分か。
2. 学習スカラー `K` は rate-distortion と同期の均衡を改善するか。
3. 構造化 `W` の学習は、単なるパラメータ増加以上の利点を持つか。
4. 学習後の結合は同期臨界近傍へ集まるか。
5. エントロピー低下は復号性能を保った圧縮か、単なる表現崩壊か。
